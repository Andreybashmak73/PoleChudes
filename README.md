# Откуда цель? — Поле чудес

Небольшая игра-барабан в духе «Поле чудес».

## Как запустить

1. Положите файл музыки **`Pole.mp3`** в корень репозитория (рядом с `index.html`).
2. Откройте `index.html` в браузере  
   или включите GitHub Pages: **Settings → Pages → Deploy from a branch → main / root**.

После включения Pages игра будет здесь:

https://andreybashmak73.github.io/PoleChudes/

Браузер не даёт музыке стартовать сама — она включается по кнопке **Начать**.
